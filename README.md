# Tube

**Search and watch videos**

Search videos and play them in 360p – or just the audio, even in the background. Double-tap to skip, mini player while you browse. With comments, no account.

## Features

- Search as usual
- Videos in 360p
- Audio only – even in the background
- Mini player and double-tap to skip
- Read comments

## Runs on

iOS 6.1.6 · jailbroken iPod touch

## Install

The easiest way is the **[Reboot App Store](https://github.com/SecondTrack/reboot)** right on the iPod.
By hand: download the `.deb` from the [latest release](https://github.com/SecondTrack/tube/releases/latest), install it with `dpkg -i`, then run `uicache`.

## Build it yourself

With [Theos](https://theos.dev) (iOS SDK with armv7):

```sh
make package
```
